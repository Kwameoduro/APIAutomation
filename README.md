# API Automation with REST Assured 

This project automates API testing using **REST Assured**, **Java**, **JUnit**, and **Maven**.  
It validates API functionality, performance, and response structures, with **Allure Reports** generated automatically via GitHub Actions CI/CD and deployed to **GitHub Pages**.

## Features
- Automated testing of REST APIs (CRUD operations)
- Validation of:
  - HTTP status codes
  - Response body data
  - Response headers
  - JSON Schema compliance
- Allure HTML reporting with historical trends.
- Continuous Integration and Deployment (CI/CD) using **GitHub Actions**.
- Live hosted reports via **GitHub Pages**.

## Tech Stack
- **Language:** Java 21
- **Build Tool:** Maven
- **Test Framework:** JUnit 5
- **API Testing Library:** REST Assured
- **Reporting:** Allure Reports
- **CI/CD:** GitHub Actions
- **Hosting:** GitHub Pages
